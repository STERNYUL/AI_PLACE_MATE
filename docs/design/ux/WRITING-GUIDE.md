# 근거 라이팅 가이드

정본: `UX-C`의 근거 라이팅 기준. `EVD-B` 문장 생성과 `CLI-C` 화면 카피는 이 문서를 같은 차단 기준으로 사용한다.

## 허용 형식

문장은 확인된 값·단위·확인 일자·확인 주체 중 필요한 사실을 조합한다. 선정 이유는 등록된 근거 속성을 참조해야 하며, 그 속성에 없는 내용을 보완하지 않는다.

| 목적 | 형식 |
| --- | --- |
| 근거 속성 | `좌석 간격 1.2m` |
| 확인 정보 | `확인 일자 2026-07-15 · 확인 주체 매장` |
| 신선도 | `확인 일자에서 90일 경과` |
| 선정 이유 | `좌석 간격 1.2m가 입력 조건의 좌석 항목에 포함됨` |

## 차단 목록

다음 표현 및 같은 뜻의 품질·분위기·순위·이용자 적합성 단정은 생성과 화면 표시에 사용하지 않는다.

`조용`, `아늑`, `분위기 좋음`, `분위기 나쁨`, `추천`, `최고`, `훌륭`, `괜찮`, `무난`, `가성비`, `인기`, `핫한`, `숨은 맛집`, `강추`, `별로`

## 처리 규칙

- 차단 표현을 뒷받침하는 확인된 속성이 있으면 표현을 사실 값·단위·일자·주체로 바꾼다.
- 근거 속성이 없으면 문장을 만들지 않는다. 후보는 근거 게이트에서 제외하고 제외 사실과 다음 행동을 표시한다.
- 차단 여부가 불명확한 표현은 **(미정 — 확정 필요)** 로 PM과 `EVD-B` 담당자가 정본을 보완할 때까지 생성하지 않는다.

## 적용 책임

| 소비처 | 적용 |
| --- | --- |
| `EVD-B` | 생성 전 차단하고 근거 속성 참조를 검증한다. |
| `CLI-C` | 화면 카피·공유 카드·상태 문구에 같은 목록을 적용한다. |
| `MCH-A` | 매장 입력 문구의 서버 측 검증 기준으로 사용한다. |
