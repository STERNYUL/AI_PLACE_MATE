- **목적** **시간과 공정성**을 검증한다. 180초가 서버 시각인지, 소환이 재현 가능한지.

### 🔗 References

### ⚠️ 소환 선정의 재현성이 §1.1 원칙의 검증 항목이다

`P2g` 미정 2번이다. **3~5곳 선정 규칙이 없으면 이 태스크는 공정성을 검증할 수 없다.**

*"노출 순서를 판매하지 않는다"* 는 선언은 **같은 조건에서 같은 결과가 나올 때만** 검증 가능하다.
재현되지 않으면 판매하지 않았다는 것도 증명할 수 없다.

`SRC-D`의 정렬 동점 규칙, `AGT-C`의 가중치 규칙과 **같은 성격의 검증 항목**이다.

**예외 (§4.5.3)** — 제안 0건 시 **Top-3로 회귀**한다 (`REQ-FUNC-025`)
**경계** — **클라이언트 시각을 앞당긴 상태**에서 마감 판정 — 서버 시각을 따른다

구현은 규칙이 모호해도 "일단 이렇게" 만들 수 있지만, 테스트는 **무엇이 통과인지** 알아야 첫 줄을 쓴다.

원장 v1.1에 검증 태스크가 0건이었던 것이 **미정 항목이 이렇게 오래 남아 있던 이유**다.
검증을 태스크로 세우자마자 7건이 차단 항목으로 드러났다.
