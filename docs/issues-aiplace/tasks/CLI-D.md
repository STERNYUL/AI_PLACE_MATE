### ⚠️ 결제 화면의 이탈은 되돌릴 수 없다

결제 요청을 보낸 뒤 인앱 브라우저가 닫히거나 지도 앱으로 돌아가면,
**사용자는 결제됐는지 모르고 우리도 모른다.**

`RSV-C`의 멱등키 미정 항목이 이 화면에서 실제 사고가 된다 — 사용자가 다시 시도하면 이중 결제다.
**클라이언트 중복 방지만으로는 부족하고 서버 멱등키가 있어야 한다.**

### 🧪 Acceptance Criteria

**Scenario 1 · 정상 — 재입력 0개**
- **Given** 선택된 후보·제안의 조건
- **When** 예약 화면에 진입함
- **Then** 조건이 채워져 있고 **사용자가 입력할 필드가 0개**다 (`REQ-FUNC-015`)

**Scenario 2 · 예외 (§4.5.3) — 결제 중 이탈**
- **Given** 결제 요청 후 앱이 백그라운드로 감
- **When** 다시 진입함
- **Then** **현재 결제 상태가 조회되어 표시**된다. 무조건 재시도 화면을 띄우지 않는다

**Scenario 3 · 경계 — 취소 시한**
- **Given** 예약 시각 2시간 전 경계
- **When** 취소 화면에 진입함
- **Then** **(미정)** 환불 가능 여부가 명시된다. 판정은 `RSV-D` 확정을 따른다

**Scenario 4 · 근거 무결성 — 금액 표기 일치**
- **Given** 화면에 표시된 결제 금액
- **When** 실제 승인 금액과 대조함
- **Then** **일치한다.** 표기와 청구가 다르면 그대로 분쟁이다
