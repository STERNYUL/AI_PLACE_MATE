### ⚠️ 평가셋이 없으면 이 태스크를 쓸 수 없다

`P1b-data.md`에서 이미 드러난 문제다. `IDX-C`는 **정규화 정확도 92%** 를 요구받지만
**92%를 무엇에 대해 측정하는지 정답셋이 없다.**

| 필요한 것 | 상태 |
| --- | --- |
| 정답 레이블이 붙은 메뉴·속성 표본 | **없음** |
| 표본 규모·상권 분포 | 미정 |
| 레이블링 주체 | 미정 |
| 갱신 주기 | 미정 |

**이 태스크의 첫 작업은 테스트 코드가 아니라 평가셋 구축이다.**
정본 Step 3이 *"AC 내용이 Step 2 이슈의 DoD로 역류"* 한다고 한 것의 실례다.

**정상** — 표준 형식 메뉴판이 정규화되어 `Attribute`로 저장된다
**예외 (§4.5.3)** — 파싱 불가 형식 입력 시 실패로 기록되고 **실패율 분모에 포함**된다
**경계** — 파싱 실패율이 정확히 3%일 때 게이트 판정 **(미정 — 이하/미만)**
**불변 규칙** — **확인 일자·주체가 없는 `Attribute`가 생성되지 않는다** (§4.5.1)
