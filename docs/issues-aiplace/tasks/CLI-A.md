### ⚠️ R6 — 진입 경로가 자사 통제 밖이다

**ADR-006**은 네이버 지도 앱 내 탭을 진입 경로로 정했고, **R6**은 그 위험을 기록한다.

| 통제 가능 | 통제 불가 |
| --- | --- |
| 앱 셸·라우팅 구현 | 인앱 브라우저의 엔진·버전 |
| 세션 개시 로직 | 지도 앱 정책 변경 |
| 성능 최적화 | 화면 크기·안전 영역 제약 |

**인앱 브라우저는 일반 브라우저가 아니다** — 스토리지 정책, 새 창 열기, 파일 다운로드, 클립보드가 제한될 수 있다.
`CLI-C`의 공유 카드 외부 전송과 `PRV-B`의 단말 저장이 여기 걸린다. **초기에 실측해야 한다.**

### 🧪 Acceptance Criteria

**Scenario 1 · 정상 — 지도 내 탭 진입**
- **Given** 사용자가 네이버 지도 앱에서 탭을 엶
- **When** 앱이 로드됨
- **Then** 세션이 개시되고 조건 입력 화면으로 진입한다

**Scenario 2 · 예외 (§4.5.3) — API 응답 실패**
- **Given** 백엔드가 `5xx`를 반환함
- **When** 화면을 렌더함
- **Then** **빈 화면이 아니라** 상태와 다음 행동이 표시된다 (§8.3 규칙 5 · `UX-F`)

**Scenario 3 · 경계 — 인앱 브라우저 제약**
- **Given** 지도 앱 내 브라우저가 로컬 스토리지를 제한함
- **When** 저장을 시도함
- **Then** **(미정 — 실측 필요)** 대체 경로가 필요하다. `PRV-B` 단말 저장이 이것에 달려 있다

**Scenario 4 · 근거 무결성 — 세션 정의 정합**
- **Given** 클라이언트가 발급한 `session_id`
- **When** `TRK-B`의 세션 판정과 대조함
- **Then** **동일한 세션 경계**를 가리킨다. 어긋나면 모든 KPI 분모가 틀린다
