### ⚠️ `TEST-005`·`TEST-007`과의 경계

`TEST-005`는 **파싱 실패 시 폴백이 동작하는가**(단건 동작)를 본다.
`TEST-014b`는 **실패율이 1.5% 이하인가**(집계 비율)를 본다. 같은 코드를 다른 축으로 잰다.

`TEST-007`은 **90일 초과 후보에 경고가 붙는가**를, `TEST-014b`는 **90일 초과 속성 비율의 주간 추적이 되는가**를 본다.

**둘을 합치지 않는 이유** — 단건 판정은 Phase 1 초반에 가능하나 **비율 판정은 질의 로그가 쌓여야** 한다.
