### 평가셋 — 원천에서 별도 레이블링 (확정 · Grill S3-T6) · `EXEC` §6.1 #1 해소

SRS는 목표 수치를 제시하지만 **무엇으로 측정하는지가 없었다.** 정답 레이블 없이는 92%를 주장할 수도 반박할 수도 없다.

| | 내용 |
| --- | --- |
| 모집단 | **원천 데이터에서 200~300건**을 별도 레이블링 |
| 분리 | **`IDX-C` 초기 적재 300건과 겹치지 않게 유지** |
| 착수 | **`IDX-B`와 같은 주**(압축 2주차) — 레이블링 자체에 시간이 든다 |
| 소비 | `IDX-B` 튜닝 · **`TEST-001`이 그대로 쓴다** |

**`IDX-C` 300건을 그대로 쓰는 안을 기각한 이유가 둘이다.**

| # | 문제 |
| --- | --- |
| 1 | **튜닝 대상과 평가 대상이 같으면 92%가 자기 채점이 된다** |
| 2 | **순환** — `IDX-C`(4주차)는 `IDX-B`(2주차) 뒤다. 그 산출물로 `IDX-B`를 튜닝할 수 없다 |

`EXEC` §5.3이 이미 *"정규화 평가셋 — Phase 0과 동시. 레이블링 작업 자체에 시간이 든다"* 를 **조기 착수 대상**으로 올려뒀다.

### 🧪 Acceptance Criteria

**Scenario 1 · 정상 — 표기 변형 통합**
- **Given** 같은 메뉴의 서로 다른 표기 (예: 띄어쓰기·외래어 표기 차이)
- **When** 정규화를 수행함
- **Then** 동일한 `canonical_key`로 매핑된다

**Scenario 2 · 예외 — 사전 미등재 표기**
- **Given** 정규화 사전에 없는 신규 표기
- **When** 정규화를 시도함
- **Then** **`canonical_key`에 원문을 그대로 두고 사전 갱신 큐에 적재한다** (확정 · Grill S3-T7). **추정 매핑하지 않는다**

**Scenario 3 · 경계 — 동음이의 메뉴**
- **Given** 표기는 같지만 실제로 다른 메뉴
- **When** 정규화함
- **Then** **통합하지 않고 별도 키를 유지한다** (확정 · Grill S3-T7)

### 정규화 정책 — 확신이 없으면 통합하지 않는다 (확정 · Grill S3-T7)

| 상황 | 처리 | 하지 않는 것 |
| --- | --- | --- |
| **사전 미등재** | `canonical_key` = 원문 · 사전 갱신 큐 적재 | 가장 가까운 키로 **추정 매핑** |
| **동음이의** | 별도 키 유지 | 표기가 같다고 **통합** |

**이 제품의 정체성이 근거다.** §1.1은 *"판정하지 않고 근거를 준다"* 이고, **추정 매핑은 시스템이 확인하지 않은 사실을 만들어내는 것**이다. 그 결과가 `SRC-C` 메뉴 질의로 나가면 §8.3 규칙 1(근거 없는 정보 노출 금지)에 걸린다.

### 미등재는 오답이 아니다 — 분리 집계한다

**원문 보존이 92%를 떨어뜨리지 않는다.** 평가셋 채점에서 두 축을 나눈다.

| 축 | 무엇을 재나 |
| --- | --- |
| **정규화 정확도** | 사전에 있는 표기를 **올바른 키로** 묶었는가 → **92% 목표** |
| **사전 커버리지** | 전체 중 사전이 **덮은 비율** → 사전 갱신으로 개선 |

합치면 사전을 넓힐수록 정확도가 떨어지는 것처럼 보여 **잘못된 인센티브**가 생긴다. `TEST-001`이 이 두 축을 따로 판정한다.

**유사도 임계값 자동 판정을 기각한 이유** — 임계값이 **새 미정**이 되고(T1 경계 규약 적용 대상), 그 값을 정하려면 평가셋이 필요해 **S3-T6과 순환**한다. 동음이의는 유사도가 100%라 임계값으로는 애초에 걸러지지 않는다.

**Scenario 4 · 근거 무결성 — 정확도 측정**
- **Given** 정답 레이블이 붙은 평가셋
- **When** 정규화 정확도를 측정함
- **Then** **92% 이상**이다 — **평가셋 구축이 선행 조건**

### ⚙️ Technical & Non-Functional Constraints
- **정확도 92%** — 목표 달성까지 반복이 필요하며 **공수 예측이 어렵다**
- `SRC-C`(FR-016) 메뉴 질의가 이 키에 의존한다 — 정규화가 틀리면 검색이 틀린다
- 사전은 **운영 중에도 갱신**되어야 한다
