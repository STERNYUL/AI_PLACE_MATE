### 🧪 Acceptance Criteria

**Scenario 1 · 정상 — SLO 계측**
- **Given** 서비스 요청이 발생함
- **When** 지표를 조회함
- **Then** p95 응답 시간과 오류율이 산출된다

**Scenario 2 · 예외 (§4.5.3) — 임계 초과**
- **Given** 파싱 실패율이 5분 윈도에서 임계를 넘음
- **When** 경보를 판정함
- **Then** **알림이 발송된다** (`REQ-NF-009` · `SRC-A`)

**Scenario 3 · 경계 — 가용성 99.5%**
- **Given** 측정 기간의 다운타임
- **When** 가용성을 산출함
- **Then** **99.5%** 기준으로 판정된다 (`REQ-NF-007`)

**Scenario 4 · 근거 무결성 — 오류율 분리**
- **Given** 결제 API와 다른 API의 오류
- **When** `REQ-NF-008`을 산정함
- **Then** **결제만 분리되어 계산**된다. 섞이면 0.1% 판정이 무의미해진다
