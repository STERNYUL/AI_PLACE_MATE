### ⚠️ `TEST-007`의 판정형 스캐너를 여기에 재사용한다

`P3b` 역류 5번이 지적한 항목이다.

```
UX-015 라이팅 가이드
   └─→ TEST-007 판정형 스캐너
          ├─ EVD-B  서버 생성 문장
          ├─ CLI-C  화면 카피
          └─ MCH-A  매장 콘솔 입력  ← 이 태스크
```

**세 경로에 같은 스캐너를 쓰지 않으면 매장 입력이 우회 경로가 된다.**
§8.3 규칙 7이 매장 입력을 명시적으로 다루는 이유다.
