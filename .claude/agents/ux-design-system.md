# UI/UX 설계

근거 — 기준 SRS §3.1.2 · 런타임 SDD §7 · `REQ-IMPL-008`~`010` · `docs/issues-aiplace/P2f-ux.md`

## 1. SRS가 시각 설계를 범위 밖에 두었다

§3.1.2는 각 화면의 **논리적 특성만** 규정한다. 따라서 —

- 근거는 **"화면이 반드시 만족해야 할 제약"** 이고, 시각 표현은 각 태스크 안에서 정한다
- `UX-A`의 `UX-001` 부분은 **SRS에 대응 요구사항이 없는 유일한 항목**이다. 착수 전 PM 승인 대상

**디자인이 항상 한 발 앞선다.** 모든 `CLI-` 태스크는 대응 `UX-` 태스크를 선행으로 갖는다.

| 디자인 | 구현 |
| --- | --- |
| `UX-A` 디자인 시스템 | `CLI-A` 앱 셸 · `CLI-E` 성능 |
| `UX-B` 조건 입력·폴백 | `CLI-B` |
| `UX-C` Top-3·신선도·라이팅 | `CLI-C` · **`EVD-B` 판정형 기준** |
| `UX-D` 공유 카드·신고 | `CLI-C` |
| `UX-E` 예약·결제·옵트인 | `CLI-D` · `PRV-B` |
| `UX-F` 빈 화면 금지 | `CLI-A` 오류 경계 · `CLI-B` · `CLI-C` |

## 2. 라이팅이 곧 요구사항이다

이 제품에서 문구는 장식이 아니라 **불변 규칙의 표면**이다.

| 규칙 | 문구에서의 의미 |
| --- | --- |
| 판정 금지 | `"조용한 편"` ✗ → **`"좌석 간격 1.2m · 2026-07-15 · 사장 확인"`** ○ |
| 근거 4항목 | 선정 이유·근거 속성·확인 일자·확인 주체가 **카드에 다 보인다** |
| 신선도 | 90일 초과는 **경고 배지를 붙여 노출**. 숨기거나 빼지 않는다 |
| 대체 명시 | 유사 메뉴로 대체했으면 **그 사실을 문구로 밝힌다** |
| 폴백 고지 | 구조화 필터로 전환됐음을 **이용자가 알게 한다** |

**판정형 어휘 기준(`UX-C`)이 `EVD-B`·`CLI-C`·`TEST-007`·`TEST-011`을 막는다.** 임계 경로 블로커다 — 먼저 확정한다.

## 3. 빈 화면 금지는 상태 설계다 (`UX-F`)

예외 처리 화면이 아니라 **정상 상태 목록**으로 그린다. **여섯 상태 전부에 화면이 있어야 완료다.**

| 상태 | 화면 | 전이 조건 |
| --- | --- | --- |
| 폴백표시 | 구조화 필터 UI + 전환 고지. **Top-3는 계속 보인다** | AI 파싱 실패·시한 초과 |
| 근거대기 | 카드 골격과 사실 값은 보이고 **문장 자리만 로딩** | 근거 문장 스트림 지연 |
| 근거생략 | 문장 없이 속성·확인 일자만. **카드를 숨기지 않는다** | 스트림 실패 |
| 유사메뉴대체 | 대체 사실 명시 | 색인 미등재 |
| 제안없음 | 빈 제안 화면 대신 **Top-3로 회귀** | 대화방 유효 제안 0건 |
| 재시도안내 | 사유와 재시도 수단 | DB·PG 오류 |

## 4. 컴포넌트는 shadcn을 따른다 (`REQ-IMPL-008`·`009`)

- `Card`·`Badge`·`Tooltip`을 쓰고 **임의 CSS 파일을 추가하지 않는다**
- 색상·간격·타이포는 `tailwind.config.ts` + shadcn 테마 변수로만 지정 (`REQ-IMPL-009`)
- **컴포넌트 내 하드코딩 값 0건**이 검증 항목이다

```tsx
// ✗ 하드코딩
<div className="bg-[#f8d7da] p-[13px]">

// ✓ 토큰
<Badge variant="destructive">
```

## 5. 후보 카드 규격 (`REQ-IMPL-010`)

```tsx
// components/candidate-card.tsx — Server Component
type CandidateCardProps = {
  reason: string; evidenceAttributes: Attribute[]
  verifiedAt: Date; verifiedBy: VerifiedBy   // 넷 다 필수. 하나라도 없으면 렌더되지 않는다
  stale: boolean                              // 경고 배지용. 제외 사유가 아니다
}
```

**`EvidenceGate`만 이 props를 조립한다.** 화면에서 임의로 만들지 않는다.

## 6. 성능이 디자인 제약이다

`REQ-NF-006` — 모바일 초기 렌더 **LCP 4G 2.5s**.

- 기본은 Server Component. **`'use client'`가 늘면 번들이 늘고 LCP가 깨진다**
- 허용된 넷 — `Countdown` · `ProposalFeed` · `ConditionForm` · `PreferenceStore`
- `UX-A`에 **모바일 성능 가이드**(`UX-013`)가 병합된 이유가 이것이다

## 7. Phase 2 화면은 게이트 뒤다

`UX-G`(대화방·제안 비교) · `UX-H`(매장 콘솔)는 **조건부 이월 단위**다. 게이트 미통과 시 통째로 버려진다.
**`UX-H`가 `SPEC-010` 콘솔 API 계약 신설을 막고 있다** — 이 계약이 없으면 `CLI-G`가 직렬화된다.

## 8. 체크리스트

- [ ] 문구에 평가·판정이 섞이지 않았는가
- [ ] 근거 4항목이 카드에 **다 보이는가**
- [ ] 여섯 열화 상태에 화면이 다 있는가
- [ ] shadcn 컴포넌트를 쓰고 **하드코딩 값이 0건**인가
- [ ] `'use client'`를 허용된 넷 외로 늘리지 않았는가
- [ ] Phase 2 화면이 Phase 1 태스크를 막고 있지 않은가
